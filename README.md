# Дом, увитый плющом

Статический лендинг учебной гостевой резиденции. HTML, CSS и JavaScript, без сборки, внешних библиотек и серверной части. Все изображения и шрифты доступны без сторонних сервисов. Шрифты Cormorant Garamond и Manrope сохранены локально; лицензии находятся в assets/fonts.

## Просмотр

Откройте `index.html` в браузере или запустите в этой папке:

```sh
python3 -m http.server 4173
```

Затем откройте http://localhost:4173.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий в GitHub.
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html`, `styles.css`, `script.js`, папку `assets` и `.nojekyll`. Не загружайте одну вложенную папку `landing` вместо её содержимого.
3. В настройках репозитория откройте **Settings → Pages**.
4. В **Build and deployment → Source** выберите **Deploy from a branch**.
5. Выберите ветку с файлами (обычно `main`) и папку **/(root)**, нажмите **Save**.
6. После завершения публикации GitHub покажет адрес сайта. Относительные ссылки позволяют сайту работать по адресу `имя.github.io/репозиторий/`.

## Что работает

- Галерея сада: рассвет, закат и ночь; управление мышью и стрелками клавиатуры.
- Телефон в иллюстрации покачивается при переходе к контактам и открывает контактное окно при нажатии.
- Часы плавно переключают две полноценные иллюстрации: солнечная гостиная и ночной сад с гирляндами, фонарями, свечами и лампой в комнате. Маятник запускается при нажатии.
- Шторы всегда открыты и являются частью иллюстрации. Управление ими удалено.
- Кнопка «Звуки сада» включает птиц днём и сверчков ночью с плавным переходом при смене времени суток. Звуковой фон синтезируется локально через Web Audio, это не полевые записи. По умолчанию звук выключен; при скрытии вкладки затихает. Телефон также может звучать, когда звук включён.
- Кнопки рядом со сценой дублируют телефон и переключение освещения на небольших экранах.
- Учтена системная настройка уменьшения движения.

## Перед настоящим запуском

Номер `123-45-67` — учебный, его указал автор проекта. Замените текст номера и все `tel:1234567` в `index.html` настоящим номером с кодом страны. Сайт не принимает заявки и не отправляет сообщения: ссылка `tel:` предлагает открыть приложение для звонков.

Название — «Дом, увитый плющом». Изображения — согласованные AI-визуализации вымышленного гостевого дома на основе фотографий автора. Адрес, стоимость и конкретные типы комнат не выдумывались. Облёт дома на видео не включён; первый экран использует фотографическую визуализацию с мягким приближением при загрузке.

Файлы исходных промптов и изображений сохранены в соседней папке `output/imagegen` исходного проекта. Для публикации они не требуются.

Более светлый фон, естественный свет первого экрана, самостоятельный заголовок и пояснение галереи с переключателями над изображением. Телефон — отдельный PNG с прозрачностью; цвет стены из дневной иллюстрации больше не переносится в ночь.

Фото сада и интерьера показаны без размытия краёв, в скруглённых рамках. Текстовые колонки на компьютере стали компактнее. Нажатие на дверцу печи или кнопку «Открыть печь» показывает огонь внутри; повторное нажатие закрывает дверцу. Огонь виден и днём, и ночью.
